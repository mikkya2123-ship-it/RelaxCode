## Кастомный брендированный установщик RelaxCode

### Контекст
Сейчас установщик — стандартный NSIS-мастер electron-builder (системные серые окна). Нужен полностью кастомный установщик: свои окна, картинки-кнопки, брендированная графика — в стиле приложения (тёмная тема #17171a, маскот-монстр, Manrope, «жидкое стекло»). Жёсткое ограничение: не сломать обновлятор — релиз обязан нести `latest.yml` + `.blockmap`, а обновление из приложения запускает новый Setup.exe с флагом `/S`.

Исследование electron-builder 26.18 показало: при кастомном `nsis.script` он всё равно передаёт все defines (APP_64, APP_64_HASH, APP_INSTALLER_STORE_FILE, UNINSTALL_APP_KEY…), подмешивает свои LangString'и/плагины и **генерирует blockmap даже для кастомного скрипта** (ищет запакованный app-64.7z байтами в exe). Значит пишем свой скрипт целиком, переиспользуя их готовые макросы через `!include` (cwd компиляции = их папка templates): `common.nsh`, `multiUser.nsh`, `installSection.nsh` (распаковка 7z + реестр + шорткаты + копия установщика в кэш обновлятора), `extractAppPackage.nsh` (SetCompress off — обязателен для blockmap), `allowOnlyOneInstallerInstance.nsh`, `uninstaller.nsh`. NSIS-тулчейн уже в кэше (nsis-3.0.4.1 + плагины Nsis7z/StdUtils/UAC/nsProcess/WinShell).

### Принятые дизайн-решения (без ответа пользователя — рекомендации)
Тёмная тема; кнопки — растровые BMP с запечённым текстом (ru/en, состояния normal/pressed/disabled); Manrope вгружается в установщик; язык — авто по системе (ru → русский, иначе английский), без диалога выбора.

### Шаг 1. Генератор ассетов — `scripts/build-installer-assets.mjs`
Источник правды — `build/installer/theme.json` (цвета, размеры, тексты). Скрипт:
- рисует страницы/кнопки через PowerShell + System.Drawing (GDI+): фоны (тёмный градиент + маскот + логотип), BMP-кнопки «Далее/Назад/Отмена/Установить/Запустить RelaxCode/Готово» в 2 языках × 3 состояния, арт готовой страницы;
- копирует лицензии license-ru.txt / license-en.txt;
- генерирует `build/installer/theme.nsh` (defines для NSIS);
- рендерит PNG-превью каждой страницы в `build/installer/preview/` — правка окон без сборки установщика;
- самопроверка BMP (магия BM, размеры) → ляжет в тест.
Шрифт: завендорить Manrope TTF (SIL OFL) + OFL.txt в `build/installer/fonts/`; установщик вгружает его AddFontResourceEx(FR_PRIVATE) на время работы, откат на Segoe UI при неудаче. Нативные метки — этим шрифтом (nsDialogs CreateFont).

### Шаг 2. Кастомный NSIS — `build/installer/installer.nsi` + `ui.nsh` + `lang.nsh`
- `package.json`: `nsis.script: "build/installer.nsi"`; убрать `license` (текст идёт нашими ассетами); добавить `test:installer` в цепочку npm test.
- Окно: ресайз до ~960×640 через .onGUIInit, заголовок «RelaxCode — Установка», штатные кнопки визарда скрыты, тёмный фон, иконка build/icon.ico.
- Страницы (nsDialogs): 1) Приветствие (арт-колонка с маскотом + заголовок); 2) Лицензия (тёмный скролл-текст ru/en, чекбокс, «Далее» недоступна до согласия); 3) Папка установки (радио «только для меня / для всех» через multiUser.nsh, путь + Обзор, оценка размера); 4) Установка (прогресс с акцентным цветом через PBM_SETBARCOLOR, шаги, кнопки скрыты); 5) Готово (арт, растровая кнопка «Запустить RelaxCode» через StdUtils::ExecShellAsUser). Удаление тоже кастомное: подтверждение → прогресс → готово, silent-пропуск как в stock.
- Кнопки: NSD_CreateBitmap + NSD_OnClick; Далее/Назад шлют WM_COMMAND в $HWNDPARENT (стандартный приём NSIS). Enter/Esc работают.
- Чек-лист совместимости с updater (обязательно): /S, /D=, --updated, --force-run, --package-file=, /allusers, /currentuser, --keep-shortcuts, --delete-app-data, --no-desktop-shortcut; InstallLocation и uninstall-ключи пишутся stock-макросами, прошлая папка читается initMultiUser; WriteUninstaller в install-секции (двухпроходная сборка uninstaller'а при кастомном скрипте не выполняется — ок, подписывания в пайплайне нет).

### Шаг 3. Тест и доки
- `scripts/installer-assets.test.mjs` (BMP-магия/размеры/ru-en/theme.nsh) + скрипт npm test:installer в цепочку.
- README: раздел про установщик (npm run installer:assets, превью, как править окна через theme.json).

### Проверка
1. `node scripts/build-installer-assets.mjs` → ассеты + PNG-превью (визуальная проверка).
2. `npm run dist` → Setup.exe компилируется чисто (warnings-as-errors), рядом .blockmap, latest.yml пайплайн не пострадал.
3. Интерактивный прогон: 5 страниц, блокировка «Далее» без лицензии, смена папки, запуск кнопкой.
4. `Setup.exe /S` → тихая установка в %LOCALAPPDATA%\Programs\RelaxCode, ключи реестра на месте, installer.exe в кэше обновлятора; `Uninstall RelaxCode.exe /S` → чистое удаление.
5. `Setup.exe /S --updated --force-run` → переустановка в ту же папку (чтение InstallLocation).
6. `npm test` зелёный.
