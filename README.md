## От задачи к изменениям в проекте

Откройте папку, подключите ИИ-провайдера и опишите задачу. Агент может изучать код, изменять файлы и запускать команды. Редактор Monaco, дерево проекта и результаты выполнения остаются под рукой.

| Возможность | Что вы получаете |
| :--- | :--- |
| **Чат, агент и план** | Обсуждение идеи, работа с проектом или подготовка плана |
| **Свои модели и API-ключи** | Выбор провайдера и модели в настройках |
| **Файлы и терминал** | Редактирование кода, поиск, команды и фоновые серверы |
| **Контроль действий** | Подтверждения инструментов, пауза, остановка и очередь задач |
| **Приложения через MCP** | Подключение внешних инструментов, включая Blender |
| **Визуальные ответы** | Изображения, интерактивные схемы и графики прямо в чате |

## Начало работы

1. Скачайте установщик `.exe` со страницы [последнего релиза](https://github.com/mikkya2123-ship-it/RelaxCode/releases/latest).
2. Установите и откройте RelaxCode.
3. В настройках подключения выберите провайдера, укажите API-ключ и модель.
4. Откройте папку проекта и начните диалог с агентом.

Запросы и переданный контекст обрабатывает выбранный вами ИИ-провайдер. Стоимость и доступность моделей зависят от его условий.

## Разработка

Понадобятся Node.js и npm. Windows — целевая платформа установщика.

```bash
git clone https://github.com/mikkya2123-ship-it/RelaxCode.git
cd RelaxCode
npm ci
npm run dev
```

| Команда | Назначение |
| :--- | :--- |
| `npm run typecheck` | Проверка типов основного процесса и интерфейса |
| `npm test` | Набор автоматических проверок |
| `npm run build` | Сборка приложения в `out/` |
| `npm run dist` | Сборка установщика Windows в `dist/` |

```text
src/main/       Агент, инструменты, MCP, процессы и хранение данных
src/preload/    Мост между Electron и интерфейсом
src/renderer/   React-интерфейс, редактор и состояние приложения
src/shared/     Общие типы, настройки и библиотека навыков
scripts/        Проверки и инструменты сборки
```

Подробное описание поведения — в [обзоре возможностей](docs/FEATURES.md). Порядок выпуска — в [руководстве по релизам](docs/RELEASING.md).
