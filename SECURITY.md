# Security Policy

## Supported versions

Security fixes are provided for the latest published RelaxCode release. Update to the newest version before reporting an issue that may already be fixed.

## Report a vulnerability privately

Do not open a public issue for a vulnerability. Use GitHub's **Report a vulnerability** button in the repository's Security tab to create a private security advisory.

Include:

- the affected RelaxCode version and Windows version;
- the impact and a minimal reproduction;
- relevant logs with API keys, paths and personal data removed;
- any suggested mitigation, if known.

You should receive an acknowledgement within seven days. Please allow time to reproduce, fix and publish an update before disclosing the issue publicly.

## Scope

Reports about unsafe command execution, secret exposure, path traversal, update integrity, MCP trust boundaries and provider credential storage are especially helpful. Provider outages, model behavior and vulnerabilities in third-party MCP servers should normally be reported to their respective owners.
