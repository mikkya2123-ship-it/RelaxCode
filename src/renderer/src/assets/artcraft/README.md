# ArtCraft app icons

The PNG files in this folder are the Craft apps' own icons, copied unmodified
from [ArtCraft Launcher](https://github.com/storytold/craft-launcher) →
`assets/app-icons/` (which in turn takes each app's icon from that app's
repository). Each icon is licensed like its app: MIT OR Apache-2.0.

The ArtCraft name, wordmark and "A" mark are trademarks of the ArtCraft Team
and are not included here.

Used by `src/renderer/src/components/ui/artcraft-icon.tsx` for the ArtCraft
connector in Settings → Applications & MCP.
