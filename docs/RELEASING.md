# Выпуск RelaxCode

1. Обновите версию в `package.json` и синхронизируйте lock-файл.
2. Выполните `npm run typecheck` и `npm test`.
3. Проверьте установщик, собранный командой `npm run dist`.
4. Выполните `npm run release` с настроенной авторизацией GitHub (`GH_TOKEN` или `gh auth login`).
5. Проверьте черновик релиза, добавьте описание изменений и опубликуйте его.

В релизе должны присутствовать установщик `.exe`, `latest.yml` и `.blockmap`. Эти файлы нужны для работы `electron-updater`.

Используется стандартный мастер NSIS с выбором языка и папки установки. Экспериментальные макеты из `build/installer/` не используются.

Текст лицензии `build/license.txt` должен сохраняться в UTF-8 с BOM. Это проверяет `npm run test:installer`.
