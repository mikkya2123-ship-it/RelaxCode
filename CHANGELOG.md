# Changelog

Notable changes to RelaxCode are documented here. Release downloads and update metadata are available on the [Releases page](https://github.com/mikkya2123-ship-it/RelaxCode/releases).

## [0.3.0] — 2026-11-13

- Refined the home screen, conversation list and visual hierarchy.
- Reworked the application mascot into a larger vector mark.
- Improved repository presentation and release packaging.
- Published a Windows x64 installer with in-app update metadata.

## [0.2.0]

- Expanded the provider catalog and OpenAI-compatible connection profiles.
- Added deeper MCP and creative-application workflows.
- Improved agent reliability, controls, backups and visual responses.

## [0.1.0]

- First public Windows release with Monaco editor, project explorer, terminal and AI chat.
