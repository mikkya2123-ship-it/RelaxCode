# RelaxCode Roadmap

This roadmap describes direction rather than guaranteed dates. Priorities may change after user feedback and technical discovery.

## Now — make the Windows release dependable

- Improve first-run setup and provider diagnostics.
- Expand automated coverage for agent tools, updater and installer behavior.
- Keep permissions, destructive-command protection and MCP trust prompts easy to understand.
- Polish English and Russian interface text and accessibility.

## Next — make daily coding faster

- Better project-wide search, diffs and change review.
- More useful context controls for large repositories.
- Easier MCP discovery, health checks and connector setup.
- Faster startup and lower memory use on long conversations.

## Later — reach more developers

- Evaluate macOS and Linux support after the Windows experience is stable.
- Add a documented extension surface for community integrations.
- Improve reproducible builds and release provenance.

Have a strong use case? Start a [GitHub Discussion](https://github.com/mikkya2123-ship-it/RelaxCode/discussions) and explain the workflow you want to improve.
